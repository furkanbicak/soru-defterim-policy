## Publishing

`index.html` is a single English page with the same layout and numbered section format as https://furkanbicak.github.io/vardiyam-policy/. The `tr/` pages are generated from the app's in-app legal texts (`npm run legal` in the app repository) so the store pages and the app always say the same thing. No dependencies or build step are needed here.

GitHub Pages publishes the root of the `main` branch. `.nojekyll` disables Jekyll processing. Edit the pages and push to `main` to update them. Review the policy whenever app data practices change and update the effective date.

This repository contains only the public policy pages, not the mobile app's source code or user data.
